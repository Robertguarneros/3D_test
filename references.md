# Reference material

The original test used two external references. The files were downloaded locally and passed to the models during the private runs, but they are not redistributed in this repository.

## Wrist and hand pose

- Source article: [Medical News Today — How to stretch your hands and wrists](https://www.medicalnewstoday.com/articles/324489)
- Direct image URL: [Download the JPEG reference](https://cdn-prod.medicalnewstoday.com/content/images/articles/324/324489/wrist-rotations.jpg)
- Image credit shown on the source page: Yana Iskayeva/Getty Images
- Local test filename: `image.jpeg`
- Use in the experiment: visual reference for the assisting-hand position and wrist/finger stretch.
- Publication status: link and attribution only; the image itself is excluded because the source page identifies it as copyrighted material and does not provide a reuse license.

## Fitness-avatar style reference

- Source asset: [The Models Resource — Male Trainer, Wii Fit](https://models.spriters-resource.com/wii/wiifit/asset/289812/)
- Direct download: [Download the PNG reference](https://models.spriters-resource.com/media/preview_icons/287/289812.png?updated=1755497786)
- Uploaded by: Goronic
- Underlying intellectual property: Wii Fit / Nintendo
- Local test filename: `image2.png`
- Use in the experiment: general inspiration for a neutral fitness-game presentation and stance.
- Publication status: link and attribution only; the ripped game asset is excluded from this repository.

The generated avatar was requested to be an original design. It should not reproduce the referenced character, face, logo, textures, or exact model.
